# Contribuer / Contributing

Les améliorations du modèle sont les bienvenues : issues et pull requests. / Improvements are welcome.

- `npm test` doit passer (Node 20 et 22) ; ajoutez un test pour tout comportement nouveau.
- Gardez le modèle **simple et sans dépendance** : il sert de point de départ, pas de framework.
- Commentez le *pourquoi* (règle de la plateforme, piège évité), pas le *quoi*.
- Aucun secret dans le dépôt. Faille de sécurité : infos@gpchat.app (pas d'issue publique).
